# GreenChat — MAX на GREEN-API

Локальный React-интерфейс для отправки и получения текстовых сообщений в MAX через GREEN-API.

## Возможности

- Подключение MAX-инстанса по API URL, ID инстанса и API-токену.
- Создание диалога по номеру телефона с проверкой получателя через GREEN-API.
- Отправка текстовых сообщений и получение входящих уведомлений.
- Локальное сохранение списка диалогов и истории в браузере.

## Структура проекта

Проект организован по Feature-Sliced Design:

- `src/app` — точка сборки интерфейса приложения.
- `src/pages` — отдельного слоя страниц пока нет: приложение одностраничное.
- `src/widgets/messenger` — экран мессенджера и координация сценариев переписки.
- `src/features/connection` — подключение GREEN-API, форма и настройки учётных данных.
- `src/entities/chat` — модель чата, сообщения и нормализация номера.
- `src/shared` — общие API-утилиты, форматирование, UI-иконки, поля, кнопки и уведомления.

Стили экранов хранятся рядом с соответствующими UI-модулями; глобальные токены и шапка приложения — в `src/app/app.css`.

## Требования

- Node.js 20.19+ или 22.12+.
- Аккаунт GREEN-API с авторизованным MAX-инстансом.

## Локальный запуск

1. Склонируйте репозиторий и откройте каталог проекта.
2. Установите зависимости командой `npm install`.
3. Запустите приложение командой `npm run dev`.
4. Откройте локальный адрес Vite, который будет показан в терминале.
5. Введите API URL, ID инстанса и токен в форме приложения. Не коммитьте токен в репозиторий.

Для production-проверки выполните `npm run build`; для линтера — `npm run lint`.

## Настройки инстанса GREEN-API

Для приёма уведомлений через HTTP API в настройках инстанса должен быть пустым `webhookUrl` и включено получение входящих сообщений. Чтобы получать сообщения, отправленные с других MAX-клиентов, включите соответствующее уведомление. Сохранённые настройки могут применяться несколько минут.

## Хранение данных и ограничения

API-учётные данные вводятся пользователем при запуске и сохраняются в `sessionStorage` текущей вкладки; готовые учётные данные не должны добавляться в исходники или репозиторий. История чатов сохраняется в `localStorage` браузера и не синхронизируется между устройствами. API-токен используется браузером в URL запросов к GREEN-API — не публикуйте его и не прикладывайте снимки Network, где он виден. Так как это клиентское приложение, токен доступен браузеру во время работы; для production нужен серверный слой.

Приложение предназначено для тестового задания и локальной проверки. Для развёртывания в production потребуется серверная часть для безопасного хранения токена, надёжная обработка очереди уведомлений и дополнительные меры защиты.
